# Java 18 - Arrays de Objetos

## Objetivo

Entender como armazenar multiplos objetos em um array, a diferenca entre criar o array e criar
os objetos, como percorrer com `for` tradicional e `for-each`, como buscar um elemento e como
lidar com posicoes nulas.

## Arquivos

- `Aluno.java` - classe com nome, matricula e nota.
- `Principal.java` - demonstra criacao, preenchimento, iteracao, busca e posicoes nulas.
- `Questoes_Java_18_Arrays.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_18_Arrays\Aluno.java Java_18_Arrays\Principal.java
java Java_18_Arrays.Principal
```
