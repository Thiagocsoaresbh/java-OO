# Java 19 - ArrayList

## Objetivo

Entender como usar ArrayList como alternativa dinamica ao array: adicionar e remover elementos
sem tamanho fixo, acessar com get(), medir com size() e comparar com o array tradicional.

## Arquivos

- `Aluno.java` - classe com nome, matricula e nota.
- `Principal.java` - demonstra criacao, add, get, remove, size e comparacao com array.
- `Questoes_Java_19_ArrayList.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_19_ArrayList\Aluno.java Java_19_ArrayList\Principal.java
java Java_19_ArrayList.Principal
```
