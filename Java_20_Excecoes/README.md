# Java 20 - Excecoes

## Objetivo

Entender o que sao excecoes em Java, como captura-las com try-catch, como lanca-las com throw
e como garantir a execucao de codigo de limpeza com finally.

## Arquivos

- `Aluno.java` - classe com validacao de nota que lanca IllegalArgumentException.
- `Principal.java` - demonstra ArithmeticException, NullPointerException, multiplos catch, throw e finally.
- `Questoes_Java_20_Excecoes.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_20_Excecoes\Aluno.java Java_20_Excecoes\Principal.java
java Java_20_Excecoes.Principal
```
